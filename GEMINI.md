## Startup sequence

1. Read README.md and docs/PRODUCT_SPEC.md before implementation.
2. Inspect current code and documentation; report what already exists.
3. Work on the smallest verified increment toward **Phase 0 — Interactive Shell**.
4. Prioritize Cluster → Node → Module drill-down and a clear event-driven architecture over decorative mockups.
5. Never claim a real distributed runtime, genuine telemetry, or completed simulation if the feature is only a prototype.
6. Verify build/tests and summarize actual results and remaining work.
